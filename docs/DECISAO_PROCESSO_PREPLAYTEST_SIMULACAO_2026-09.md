# Decisão de processo — adiar playtest humano e usar simulação pré-playtest

**Status:** APPROVED  
**Domain:** produto / processo de validação  
**Authority:** GitHub  
**VerifiedAgainst:** decisão explícita do autor em 2026-09-23/24 + estado técnico atual  
**Supersedes:** prioridade operacional imediata de playtest humano enquanto a build não estiver apresentável

## Decisão

Enquanto o jogo não estiver em estado adequado para apresentação às crianças:

- o playtest mediado humano das passivas fica **adiado**;
- a equipe/IA deve avançar com **simulações técnicas e dirigidas** para reduzir incerteza mecânica;
- essas simulações não podem ser rotuladas como evidência humana;
- percepção, compreensão, diversão, frustração, justiça e estratégia espontânea permanecem pendentes;
- nenhuma simulação isolada autoriza buff/nerf automático.

## Motivo

Executar agora uma sessão “manual” sem crianças seria apenas uma simulação feita pelo próprio autor e consumiria tempo sem produzir a evidência humana que o protocolo pretende coletar.

## Consequência no roadmap

A fase operacional imediata passa a ser:

`validação pré-playtest por simulação dirigida das passivas de espécie`

O playtest mediado continua sendo um portão futuro, condicionado a uma build suficientemente apresentável para crianças.

## Limites

Esta decisão muda **timing/processo**, não:

- regras de combate;
- valores de passivas;
- PWR;
- ENE;
- boss;
- critérios humanos do protocolo.
