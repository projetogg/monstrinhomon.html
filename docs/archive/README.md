## Regra de uso

Antes de usar qualquer arquivo daqui:

1. consulte `docs/AI_ENTRYPOINT.md`;
2. confira `docs/PROJECT_STATUS.md`;
3. verifique `docs/AUTHORITY_MAP.md` e `docs/DECISION_LOG.md`;
4. compare o documento com a `main` e os testes atuais;
5. trate recomendações antigas como históricas, salvo decisão posterior registrada.
